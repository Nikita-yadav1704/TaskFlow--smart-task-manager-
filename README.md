# TaskFlow | Smart Task Manager

> A modern, responsive and feature-rich task management web application designed to help users organize tasks, prioritize work, track productivity, and manage their daily workflow efficiently.

## 📌 About the Project

TaskFlow is a smart task management application built with a focus on **productivity, simplicity, and modern user experience**.

The application allows users to create, organize, search, prioritize, complete, and manage tasks from a centralized dashboard. It also provides productivity tracking, task analytics, smart sorting, calendar support, theme customization, and voice-enabled search to make everyday task management faster and more convenient.

The interface is designed to remain visually clean and intuitive while supporting both **Dark Mode and Light Mode**.

---

## ✨ Key Features

### 📝 Task Management
- Create tasks with title and description
- Assign task categories
- Set task priority
- Set due dates
- Mark tasks as completed
- Edit and delete tasks
- View detailed task information
- Pin important tasks for quick access

### 🔍 Smart Search & Filtering
- Real-time task search
- Search tasks by relevant information
- Filter tasks based on their status
- Filter tasks according to priority
- Quickly find important or pending tasks

### 🧠 Smart Task Organization
- Pinned tasks are prioritized
- Important tasks are highlighted
- Overdue tasks can be identified easily
- Tasks can be organized according to priority and due date
- Drag-and-drop task organization

### 📊 Productivity Dashboard
- Total task count
- Completed task count
- Pending task count
- Important task count
- Overall task completion percentage
- Visual task progress indicator
- Productivity score
- Productivity insights

### 📈 Analytics
- Dedicated analytics view
- Task completion statistics
- Productivity overview
- Visual progress tracking
- Insights based on task activity

### 📅 Calendar
- Integrated calendar interface
- View and manage tasks according to dates
- Helps users plan upcoming work and deadlines

### 🎤 Voice Search
- Voice-enabled task searching
- Uses browser speech recognition capabilities
- Allows users to search tasks using voice commands

### 🌓 Theme Customization
- Dark Mode
- Light Mode
- Theme preference is preserved using browser storage
- UI remains visually consistent across both themes

### 💾 Local Data Persistence
- Uses **Local Storage** to preserve tasks
- Tasks remain available after refreshing the browser
- User preferences such as theme settings are also stored locally

### 🔔 Interactive User Experience
- Toast notifications
- Confirmation dialogs
- Task details modal
- Delete confirmation modal
- Interactive buttons and controls
- Smooth UI interactions
- Responsive interface
